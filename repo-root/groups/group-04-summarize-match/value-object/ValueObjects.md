# Value Objects — index

Fiches par Value Object pour le domaine `summarize-match`.

- [PlayerId](PlayerId.md) — identifiant d'un joueur.
- [TeamId](TeamId.md) — identifiant d'une équipe.
- [MatchId](MatchId.md) — identifiant d'un match.
- [EventId](EventId.md) — identifiant d'un événement de timeline.
- [MatchTime](MatchTime.md) — temps de jeu normalisé.
- [Score](Score.md) — score home/away encapsulé.
- [MatchResult](MatchResult.md) — résultat d'un match du point de vue d'un joueur.
- [MatchStatus](MatchStatus.md) — état courant d'un match dans le read model.
